# pol-contact

Τηλεφωνικός κατάλογος των υπηρεσιών του Δήμου Πολυγύρου σε μορφή JSON (ανοικτά δεδομένα).

## Το αρχείο

`contact_data.json` — μία εγγραφή ανά γραμμή του καταλόγου, με τα πεδία:

| Πεδίο | Περιεχόμενο |
|---|---|
| `ΙΔΙΟΤΗΤΑ \| ΥΠΗΡΕΣΙΕΣ` | Θέση ή αντικείμενο |
| `ΟΝΟΜΑΤΕΠΩΝΥΜΟ` | Ονοματεπώνυμο |
| `ΤΗΛΕΦΩΝΟ` | Τηλέφωνο υπηρεσίας |
| `E-MAIL` | Ηλεκτρονική διεύθυνση |
| `ΚΙΝΗΤΟ/E-MAIL 2` | Δεύτερο στοιχείο επικοινωνίας, όπου υπάρχει |
| `ΤΜΗΜΑ` | Διεύθυνση ή Τμήμα στο οποίο ανήκει η εγγραφή |

## Πηγή και ενημέρωση

- Πηγή: η σελίδα «Επικοινωνία» του Δήμου, https://polygyros.gr/epikoinonia/
- Ενημερώνεται αυτόματα κάθε Δευτέρα και Πέμπτη στις 09:00 (ώρα Ελλάδας).
- Το αρχείο αντικαθίσταται ολόκληρο σε κάθε ενημέρωση. Μην το διορθώνετε με το χέρι: οι αλλαγές γίνονται στη σελίδα του Δήμου.
